# superrw92 (Super-Read/Write_1992)
## RU
Модифицированный super образ для устройства Infinix Note 30i (X6716), предназначенный для стоковой прошивки V1992.
Этот образ конвертирован в режим R/W (ext4), очищен от многого кол-ва лишних приложений, оптимизирован и имеет дополнительные функции/фишки, которых нету в стоковой системе
Потихоньку образ в будущем будет иметь больше полезных фишек
## EN
A modified super.img for the Infinix Note 30i (X6716), designed for the stock V1992 firmware.
The image has been converted to R/W mode (ext4), debloated by removing numerous unnecessary apps, optimized, and enhanced with additional features and modifications that are not available in the stock system.
The image will gradually receive more useful features and improvements in future updates
